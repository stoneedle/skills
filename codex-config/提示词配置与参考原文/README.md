## 💡 常用场景与推荐选型

1. **如果你想要最省心、最强大的日常开发体验**：  
   保持官方 Astra 默认基础提示词不动，参考 [config.template.toml](config.template.toml) 中的 `developer_instructions` 追加你的中文回复与代码偏好。
2. **如果你怀念 GPT-5.5 时代的灵动语调或需要写极其惊艳的前端/3D 页面**：  
   打开 [旧版官方原版-GPT-5.5-出厂提示词.zh.md](旧版官方原版-GPT-5.5-出厂提示词.zh.md)，将其中的 `Frontend guidance` 章节提炼为你专属的 UI 设计技能（Skill）。
3. **如果你想学习顶级重构与模块规范**：  
   阅读 [旧版-GPT-5.5-基础提示词.zh.md](旧版-GPT-5.5-基础提示词.zh.md) 中的 `Architecture Taste` 和 `Compatibility` 章节。
